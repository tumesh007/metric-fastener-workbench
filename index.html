Metric Fastener Workbench

Configure printable M3, M4, or M5 nuts and bolts, then export a single part or a multi-part print layout.

For one combined print file, set the nut and bolt counts and export the batch STL. The parts stay spaced apart as separate pieces in one STL. For direct STL export, start the local server with node server.mjs and open its page.
