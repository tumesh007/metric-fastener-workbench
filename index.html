Metric Fastener Workbench

ISO coarse metric (M1–M10) CAD generator based on FreeCAD Fasteners Workbench taxonomy. Download Mac App package.

Direct STL export renders watertight binary STL in browser. Works offline & on GitHub Pages.

Model Preview

Printed plastic hardware is for prototype, electronics, and light-duty mounting. Fasteners are pre-oriented cap-down (Z = 0) for support-free FDM 3D printing.
